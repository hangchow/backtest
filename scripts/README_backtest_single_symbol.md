## 结果解读

- 港股这三只样本里，`RSI reversion` 全部排第一，说明在当前这一年窗口和这组三只股票上，均值回归触发比趋势类默认参数更激进也更有效。
- 美股单标没有被一套策略完全统治：`RSI reversion` 拿下了 `US.GOOG` 和 `US.NVDA`，`EMA + RSI` 拿下了 `US.MSFT` 和 `US.TSLA`。这说明美股里“趋势过滤 + 回撤买入”比纯 RSI 更均衡，但不是所有票都适合。
- `EMA cross` 在单标层面没有拿到任何第一名。它更像低换手、低解释复杂度的对照组，而不是当前的收益主力。
- `EMA + RSI bull range` 在港股上明显强于普通 `EMA + RSI`，但在美股上没有把优势稳定延续到全部标的，说明它更像一组对特定市场风格更敏感的参数集，而不是通用替代品。

## 实现备注

- 这组结果是通过 [`compare_backtests.py`](compare_backtests.py) 汇总生成的，它会按“前一年预热、后一年记分”的相同口径跑 4 套默认单标策略，并输出数据概览、回测对比和最佳结果表。
- 这份文档目前不包含股票池轮动或股票池统一资金回测；相关内容分别在港股 / 美股股票池文档里维护。
