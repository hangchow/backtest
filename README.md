# Backtest

## 项目概览

这个项目基于腾讯控股 `HK.00700` 1 分钟 K 线数据，做几个简单策略的样本内回测。

当前数据范围：

- 标的：`HK.00700`
- 区间：`2025-03-07 09:30:00` 到 `2026-03-06 16:00:00`
- 数据粒度：`1 分钟`
- 文件数量：`246` 个交易日 CSV

## 数据目录

- 数据目录：`data/HK.00700/`
- 单文件格式：`HK.00700_YYYY-MM-DD.csv`
- 字段：`time_key, open, close, high, low, volume`

抓取脚本和说明：

- [抓取脚本说明](scripts/README_fetch_history_1m.md)

## 当前策略结果

以下结果都基于同一批腾讯分钟数据、同一区间、初始资金 `100000` 港币。
这些结果已在 `2026-03-08` 用修正后的 RSI 实现重新跑过；默认参数结果与此前一致，但仍然只是样本内结果，且未计手续费、滑点和港股整手限制。

### 1. RSI 反转

- 脚本：`scripts/backtest_rsi_reversion.py`
- 说明：[RSI 策略说明](scripts/README_backtest_rsi_reversion.md)
- 默认参数：`RSI(6)`，`buy < 30`，`sell > 60`，仓位 `100%`，允许隔夜
- 结果：
  - 期末总资产：`604046.80`
  - 总收益率：`504.05%`
  - 最大回撤：`-10.19%`
  - 交易次数：`3628`

### 2. EMA 金叉死叉

- 脚本：`scripts/backtest_ema_cross.py`
- 说明：[EMA 策略说明](scripts/README_backtest_ema_cross.md)
- 默认参数：`EMA(30)` / `EMA(120)`，仓位 `50%`，默认日内平仓
- 结果：
  - 期末总资产：`93218.80`
  - 总收益率：`-6.78%`
  - 最大回撤：`-9.24%`
  - 交易次数：`786`

### 3. EMA + RSI 组合策略

- 脚本：`scripts/backtest_ema_rsi_combo.py`
- 说明：[EMA + RSI 策略说明](scripts/README_backtest_ema_rsi_combo.md)
- 默认参数：`EMA(20) > EMA(240)` 趋势过滤，`RSI(6)`，`buy < 40`，`sell > 55`，仓位 `100%`，允许隔夜
- 结果：
  - 期末总资产：`476907.80`
  - 总收益率：`376.91%`
  - 最大回撤：`-3.70%`
  - 交易次数：`3988`

## 当前结论

- 样本内收益最高的是 `RSI 反转`。
- 如果同时看收益和回撤，`EMA + RSI` 组合策略更均衡：
  - 收益显著高于纯 EMA
  - 最大回撤明显低于纯 RSI
- 纯 `EMA 金叉死叉` 在这批样本里表现较弱。

## 已知缺陷

- 目前是样本内回测，只在同一段数据上调参与评估，存在明显过拟合风险。
- 没有做训练集 / 验证集 / 测试集拆分。
- 没有加入手续费、平台费、印花税、滑点。
- 默认按分钟收盘价成交，真实成交未必能拿到这个价格。
- 没有处理港股整手限制，回测里允许按股数买卖。
- 没有处理停牌、除权除息、公司行为等更复杂情况。
- 目前只回测了单一标的 `HK.00700`。

## 风险提示

- 文档里的高收益结果不代表可实盘复制。
- 单个策略页里展示的数字也同样只是样本内回测快照，不是可直接外推的收益预期。
- 交易次数很多，加入真实费用后，收益会显著下降。
- 使用分钟级数据做高频触发时，执行延迟和滑点会非常敏感。
- 样本内最优参数，未来很可能失效。

## 建议的下一步

- 加入港股手续费、交易征费、印花税。
- 增加整手限制和现金不足约束。
- 做样本外测试，而不是只看当前这一年。
- 把交易明细、权益曲线、回撤曲线导出。
- 增加更多标的，避免只对腾讯单票过拟合。
